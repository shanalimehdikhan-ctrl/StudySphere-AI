StudySphere AI is an AI-powered study assistant that helps students learn faster.

It can:
- Explain any topic
- Generate Notes
- Create Flashcards
- Generate Quizzes
- Solve Questions & Problems

It is designed for school, college and university students.

## 🤖 AI Feature

The app uses Google Gemini AI.

The AI receives the student's topic and performs one of these tasks:

- Explain
- Notes
- Quiz
- Flashcards
- Problem Solving

The AI is instructed to generate clear, student-friendly and well-formatted responses.
